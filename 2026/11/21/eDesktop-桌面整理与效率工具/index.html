eDesktop：桌面越堆越乱？让这只小猫帮你整理，顺便管起待办和专注

#资源库 #软件推荐

一句话定位：把乱糟糟的桌面收进收纳盒，再让一只叫小栖的桌宠帮你记待办、管专注，Windows 上的开源桌面整理工具。

一、它是什么，为什么值得看

桌面文件越攒越多，想整理又懒得一遍遍打开资源管理器——把文件拖进这个文件夹、再拖回那个文件夹，整理一次够累半天。eDesktop 就是冲着这个麻烦来的。

它是一个 Windows 10/11 上的桌面效率工具，把收纳盒、便签、待办、番茄钟做成了可以直接摆在桌面上的组件，组件能自由拖动、缩放、跨显示器摆放。后来作者又往里面加了一只叫「小栖」的桌宠，除了陪在桌面上，还能听懂你说话：说一句”帮我整理桌面”，它会先给一份整理方案，你确认之后才动手移文件；说”二十分钟后提醒我取快递”，就真的会写进待办。

项目用 Electron + React + TypeScript 编写，MIT 开源、完全免费，数据全部留在你自己的电脑上。

二、核心亮点

  1. 桌面整理不用再开资源管理器：收纳盒可以收纳文件、文件夹、快捷方式和系统图标，拖动排序、双击打开。桌面从”堆着一堆图标”变成”东西有地方放”，这是最直接解决痛点的一条。

  2. 先给方案，你确认了才动文件：对小栖说”帮我整理桌面”，它会参考已有收纳盒的名字和内容，给出每个文件该去哪、为什么这么分。你点确认之后才会真正移动，不想动的文件在预览里取消勾选就行。整理工具最怕的就是”一键全自动”，这个设计让人放心。

  3. 一只听得懂话的桌宠，不只是摆件：除了文字聊天，按 Ctrl+Alt+V 可以直接开口说话，回复在桌面气泡里显示。记待办、设提醒、改天气播报、开番茄钟，都能用一句话完成，还支持接着补充——“提醒我取快递”说漏了时间，再补一句”二十分钟后”即可。

  4. 数据全在自己手里，录音不落盘：设置、待办、聊天、记忆、缓存和离线语音模型都放在程序旁的 data 文件夹，软件放哪个盘，数据就跟到哪个盘。录音只在内存里处理、不保存音频，识别出的文字按聊天记录存本地；对话发往本机 Ollama，推理在本机完成。

  5. 布局能存快照，多屏也能摆：在控制中心可以把当前布局和配置存成快照，需要时恢复；组件支持跨显示器摆放，窗口位置和图标位置都有对应处理。

⚠️ 使用前提与避坑：只支持 Windows 10/11 x64，没有 macOS 和 Linux 版。桌宠的聊天和桌面整理功能需要本机先装好 Ollama 并准备一个聊天模型，没装的话便签、待办、番茄钟这些组件照常能用，但语音交互和整理桌面用不了。语音功能首次会下载约 229 MB 的离线识别模型，之后无需 API Key。软件没有商业代码签名，Windows 可能弹 SmartScreen 提示，请从官方 Release 下载并核对附带的 SHA-256 校验值。收纳盒移动的是真实文件，不是软链接。

三、实际体验：几个真实场景

下面几个场景按项目官方文档和 v1.2.0 的更新说明整理，具体表现以你本机运行效果为准。

场景一：桌面文件堆成山

桌面上散着 PDF、Word、截图和一堆下载来的压缩包，一个个归类太费神。把话说给小栖听——“帮我整理桌面”，它会先扫描桌面，给出一份方案：每个文件放进哪个收纳盒、分类的理由是什么，预览里都能看得到。

判断依据不只是文件名。PDF、DOCX、TXT、Markdown 和 CSV 还会读取少量正文作为参考，所以一份文件名很长、没写”简历”的求职材料，也能结合内容判断出该放进”工作”。目录整体收纳，不会递归翻里面的文件，desktop.ini 这类系统配置会被直接略过。

分得不合适的，取消勾选，或者补一句”按项目整理”重新生成。拿不准的项目可以先留在桌面，不用勉强归类。

场景二：随手记点东西

桌面上的便签组件适合临时记，待办组件可以分组安排。想快速加一条，直接对小栖说”二十分钟后提醒我取快递”，它会写进待办的”临时安排”分组。接着说”还是改成半小时吧”，改的就是刚才那一条，不用重新描述。

习惯也能记下来：”以后写代码 45 分钟，看书 25 分钟”，下次直接沿用；说”这次 20 分钟”只影响当前这一次，不会覆盖掉习惯。这些记忆在控制中心 → 小铃铛 → 小栖记住的事里可以逐条查看和忘记，原话来源也一并留着。

场景三：不想打字，直接说

按 Ctrl+Alt+V 开始录音，再按一次结束并自动发送，小栖会竖起耳朵、声波随音量变化，回复直接出现在桌面气泡里。按 Esc 或点 × 可以取消，每次最多录音一分钟。

说一句”陪我专注一刻钟”，番茄钟就启动了，专注和休息结束时都有提醒，提醒声音可以关闭。需要留意的是，番茄钟目前支持立即开始、停止和查询，暂不支持预约未来某个时间开始。另外，应用退出或桌宠关闭期间是不会弹出提醒的，别指望它当后台常驻的提醒器。

场景四：管好桌面的一切

组件的开关、新建收纳盒、调整桌宠、管理快照，都在系统托盘 → 控制中心里完成，不用在桌面上到处找设置入口。

所有组件都可以拖动、缩放、跨屏摆放，不喜欢回复太长，也能在小铃铛 → 聊天偏好里改称呼、回复长短和追问方式——直接告诉小栖”以后叫我小李，回答短一点，不要追问我”也行，两种入口改的是同一份偏好。偶尔想多听一点，说”这次详细一点”，不会把平时的偏好一起改掉。

四、适合谁 / 不适合谁

适合想要整理桌面、又不想在资源管理器里反复拖拽的人；想要一个统一的待办和专注入口、顺手用语音操作的 Windows 用户；在意数据存放位置、希望软件完全本地运行的人。

不太适合非 Windows 用户——目前只有 Windows 10/11 x64 版。如果你的桌面本来就很干净，只需要个待办清单，那用更轻量的工具就够，没必要装一个 Electron 应用。项目还比较年轻（仓库 2026 年 8 月建立，目前 star 和 fork 都不多），功能在快速迭代，遇到边界情况建议直接提 Issue，作者的响应和文档的细致程度都能看出是认真在做。

五、获取与下载

  • GitHub 仓库：https://github.com/six486486/eDesktop
  • 版本：当前最新为 v1.2.0（2026-09-14 发布，主题”小栖会整理桌面了”）
  • 支持平台：Windows 10 / 11 x64
  • 安装方式：下载便携 ZIP（eDesktop-1.2.0-windows-x64.zip，约 150 MB），完整解压后运行 eDesktop.exe，整个文件夹都要保留。无需安装，也附带 .sha256 校验文件。

想用桌宠的话，额外两步：

  1. 安装并启动 Ollama，准备一个聊天模型，小栖会自动连接本机默认服务。
  2. 首次使用语音功能时，按 Ctrl+Alt+V 触发约 229 MB 离线识别模型下载，完成后再按一次开始录音。

从旧版升级：先从系统托盘正常退出，替换程序文件时务必保留自己的 data 文件夹——里面是你的设置、待办、聊天记录和收纳文件。移动软件时携带整个文件夹；如果开启了开机启动，移动后请关闭再重新开启一次，让 Windows 记录新路径。

从源码运行：需要 Node.js 22.13 或更高版本（建议 24），技术栈是 Electron、React、TypeScript 和 Vite。

打包成便携 ZIP 用 npm run package:portable。打包前先退出正在运行的 eDesktop，分发包不会包含个人数据。

如果你也在用 eDesktop，欢迎在评论区聊聊你的桌面配置、小栖的模型选了哪个，或者遇到的踩坑经历。
