二、环境安装与验证

🟢 Step 1: 安装 Git

下载地址

👉 https://git-scm.com/download/win

核心安装步骤

  1. 双击下载的 .exe 安装程序
  2. 重要勾选：在 “Adjusting your PATH environment” 选项中，勾选 “Use Git and optional Unix tools from the Windows Command Prompt”（确保 Git 加入 PATH）
  3. 一路默认点击 Next 完成安装

✅ 验证方法

打开 PowerShell 或 CMD，输入：

预期输出示例： git version 2.45.0.windows.1

若显示版本号 → ✅ Git 安装成功
若提示 'git' 不是内部或外部命令 → ❌ 重新安装，确保勾选 Add to PATH

🟢 Step 2: 安装 Node.js

💡 推荐使用 LTS（长期稳定版），生产环境首选 LTS 版本

下载地址

👉 https://nodejs.org （选择 LTS 版本）

核心安装步骤

  1. 下载 Windows Installer（.msi）
  2. 双击运行安装程序
  3. 务必勾选 Add to PATH（让 npm 也能在全局使用）
  4. 按默认选项完成安装

四、GitHub Pages 仓库配置

1. 创建 GitHub 仓库

  1. 登录 GitHub，点击右上角 + → New repository
  2. 仓库名必须是：你的GitHub用户名.github.io（⚠️ 严格格式要求）
  3. 选择 Public（GitHub Pages 不支持私有仓库）
  4. 不要初始化 README、.gitignore 或 License（保持空白仓库）
  5. 点击 Create repository

示例：如果你的用户名是 Impossible0105，仓库名应为：Impossible0105.github.io

2. 获取仓库地址

创建成功后，点击 Code → 复制 HTTPS 地址（格式如：https://github.com/Impossible0105/Impossible0105.github.io）

十四、问题排查速查表

现象 可能原因 解决方法
git: 'clone' is not a command Git 未安装或未加 PATH 重新安装 Git，勾选 Add to PATH
hexo: command not found Hexo 未全局安装 运行 npm install -g hexo-cli
本地能访问但访问不到 github.io 部署失败或仓库名格式不对 检查 _config.yml 中的 repo 和 branch，确认仓库名为 username.github.io
页面样式错乱 缺少主题依赖 执行 npm install hexo-renderer-pug hexo-renderer-stylus --save
SSH 连接被拒绝 公钥未添加 在 GitHub Settings → SSH Keys 添加你的公钥
部署速度慢 npm 源慢 设置镜像 npm config set registry https://registry.npmmirror.com
